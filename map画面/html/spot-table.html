表の中を直接書きかえて、最後に「保存」を押すと、まとめて保存されます。変えた行は色が付きます。

CSV で書き出して Excel やスプレッドシートで直し、読み込むこともできます（読み込んだだけでは保存されません）。新しい聖地は「ID」を空にした行で足せます（ID は自動で付きます）。新しい聖地には地図の場所（緯度・経度）が必要です。

ID を変えると、利用者のスタンプ・お気に入り・保存したルートは古い ID のまま残り、表示されなくなります（おすすめルートは自動で付け替えます）。必要な時だけ変えてください。

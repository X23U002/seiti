# 聖地の画像

地図のスポット詳細やスタンプに表示する画像を置くフォルダです。作品ごとにフォルダを分けています。

```
images/spots/
└── eupho/   響け！ユーフォニアム（例：eupho/eupho_s0701.jpg）
```

ファイル名は **作品のフォルダ名_聖地のID** にします（例：`eupho_s0701.jpg`）。聖地のIDは、管理ページの「聖地」タブや「聖地の一括編集」に出ています。

## 使ってよい画像

- **現地で自分たちが撮った写真など、使ってよい写真だけ**を置いてください。
- **アニメの場面の画像（スクリーンショットなど）は、著作権上使えないので置かないでください。**
  `images/spots/anime/` を指している聖地があっても、アプリでは表示しません。

## 画像の追加のしかた

1. GitHub で `map画面/images/spots/` の中の作品のフォルダを開く（無ければ新しく作る）
2. 右上の「Add file」→「Upload files」で画像を選び、「Commit changes」を押す
3. 管理ページの「聖地」タブで聖地の「編集」を開き、「画像」欄に `eupho/eupho_s0701.jpg` のように入れて保存する

GitHub Pages に反映されるまで数分かかります。管理ページのプレビューに出ない時は、少し待ってから開き直してください。

## ファイルのおすすめ

- ファイル名は半角の英数字にする（日本語や空白は避ける）
- 形式は JPEG（.jpg）・PNG（.png）・WebP（.webp）
- 横 1200px 程度、1枚 500KB 以下（大きいと地図やスタンプ帳の表示が遅くなる）

# 聖地の画像

地図のスポット詳細に表示する画像を置くフォルダです。

## 画像の追加のしかた

1. GitHub でこのフォルダ（`map画面/images/spots/`）を開く
2. 右上の「Add file」→「Upload files」で画像を選び、「Commit changes」を押す
3. 管理ページの「聖地」タブで聖地の「編集」を開き、「画像」欄にファイル名（例：`ujibashi.jpg`）を入れて保存する

GitHub Pages に反映されるまで数分かかります。管理ページのプレビューに出ない時は、少し待ってから開き直してください。

## ファイルのおすすめ

- ファイル名は半角英数字（例：`uji-bridge.jpg`）。日本語や空白は避ける
- 形式は JPEG（.jpg）か WebP（.webp）
- 横 1200px 程度、1枚 500KB 以下（大きいと地図の表示が遅くなる）
- 自分で撮った写真など、使ってよい画像だけを置く（アニメの画面写真などは置かない）

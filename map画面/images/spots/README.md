# 聖地の画像

地図のスポット詳細に表示する画像を置くフォルダです。写真の種類ごとにフォルダを分けています。

```
images/spots/
├── anime/   アニメの場面（例：anime/s11.png）
└── real/    現地の写真（例：real/s11.jpg）
```

ファイル名は **聖地のID** にします（例：`s11.jpg`）。聖地のIDは、管理ページの「聖地」タブの一覧に「ID：s11」のように出ています。

## 画像の追加のしかた

1. GitHub で `map画面/images/spots/anime/` か `map画面/images/spots/real/` を開く
2. 右上の「Add file」→「Upload files」で画像を選び、「Commit changes」を押す
3. 管理ページの「聖地」タブで聖地の「編集」を開き、「画像」欄に `real/s11.jpg` のように入れて保存する

GitHub Pages に反映されるまで数分かかります。管理ページのプレビューに出ない時は、少し待ってから開き直してください。

## ファイルのおすすめ

- ファイル名は聖地のID＋拡張子（例：`s11.jpg`）。日本語や空白は避ける
- 形式は JPEG（.jpg）・PNG（.png）・WebP（.webp）
- 横 1200px 程度、1枚 500KB 以下（大きいと地図の表示が遅くなる）
- 自分で撮った写真など、使ってよい画像だけを置く。アニメの場面の画像は著作権に気をつけ、公式が使用を認めている範囲で使う
